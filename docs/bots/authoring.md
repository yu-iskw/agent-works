# Design and operate a bot

Open a teammate's details and select **Design and run a bot**. Describe the work in the design form. The teammate proposes a fixed workflow; it does not run the work when it proposes a draft. If the proposal needs changes, read the diagnostics and send another request. You can also ask for a change to an existing draft or published bot.

Review the entire preview before publishing. Check the ordered steps and their dependencies, connector capabilities and queries, and the package, version and digest of each skill. The external-agent section identifies the agent and the data sent to it. Review the schedule timezone and missed-run policy, approval mode and checkpoints, limits, and result destination. Use the export link to save the revision and its provenance.

Select **Confirm and publish this revision** only when the preview describes the work you intend. Confirmation applies to the revision and digest on that page. If another edit changes the draft first, the confirmation is refused. Reload, review the current preview and confirm again. Publishing a newer revision does not change runs already started from an older one.

Use **Start run** on the bot page to start the published revision. Open a run to see the status of each step and any last error. A pending approval shows the action to review with **Approve** and **Decline** buttons. Available actions also include cancelling a run, retrying a failed step, or recording the outcome of a step whose external outcome is uncertain. Provide a note when resolving an uncertain outcome. Review the result and cost completeness on the run page. Partial or unknown cost means the shown figures do not account for every cost.
