## Limitations

- Identity and sources are simulated in this stack. Publication writes to a fixture document store, not Google Docs. These are labelled in the UI and are not live integration evidence.
- The running-work and recoverable-failure visual captures render seeded rows (`llm_mode` `stub`), labelled on the contact sheet; every other capture is real Gemini output.
- U20 has no sessions yet. Until three reviewers have run the script in [`UX_REVIEW.md`](UX_REVIEW.md), the milestone is a technical pass with a human gate pending, not complete.
- The "Generate and scan SBOM" check now runs only on pushes to main, weekly and on manual runs (#180). It still reports `minimatch` GHSA-g3hv-75wg-m249. The fixed 11.0.1 clears the 7-day release-age rule on 2026-11-04 07:26 JST and is pinned then, with no quarantine exclusion.
