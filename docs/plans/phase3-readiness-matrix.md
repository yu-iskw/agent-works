# Phase 3 readiness matrix

This file maps [RFC-001](../rfcs/RFC-001-Enterprise-Gemini-Style-Agent-Platform.md) sections 15 through 21 and decisions D-01 through D-12 to gated work. [Issue 104](https://github.com/yu-iskw/agent-works/issues/104) is planning only. This file does not approve Phase 3 and does not declare production ready.

The RFC body status line is PROPOSED. The front matter status is Proposed, and that field requires architecture and security review. The RFC states that it has completed no production deployment, benchmark, security test, cost quotation, or compliance certification. The decision requested line says not to approve unrestricted production autonomy or blanket data access.

The disposition recommendation says "Approve Phase 0 and a limited Phase 1 with read-only, non-sensitive, explicitly permission-tested sources." That sentence is a recommendation and not a signature. The same paragraph says to treat later approvals, agent autonomy, Workspace write scopes, long-term memory, and multi-agent delegation as independently gated expansions. The disposition names these signatory roles before production:

- Enterprise Architect
- Platform Engineering
- Security Architecture
- Workspace/IAM Admin
- Data Governance/Privacy
- SRE
- Business Product Owner

Section 20 states "Implementation cannot responsibly progress to unrestricted production deployment until D-01 through D-09 have recorded decisions." D-10, D-11, and D-12 are open and sit outside that sentence. No Accepted ADR is keyed to any D-id. [ADR 0001](../adr/0001-typescript-first-with-adk-js.md), [ADR 0002](../adr/0002-monorepo-layout.md), and [ADR 0003](../adr/0003-pilot-decisions.md) do not close one. There is no `docs/adr/0004-managed-services-adoption.md` and no `docs/adr/0005-retrieval-arm.md`. The notes in RFC section 3 labeled ADR-004 and ADR-005 are not those files.

ADR 0003 records a pilot region, a test tenant, no retrieval under that record, no write tool under that record, and no spending cap on the dev project. Those answers leave D-01, D-02, D-03, D-04, and D-10 open. ADR 0003 states "RFC-001 section 17.2 hard stops do not apply to the dev project. A later record changes that, not this one."

## How to read a row

A later issue reads one control row. It copies that row's stop and go. Its diff stays inside that row's write path. It does not copy a decision question, owner role, required evidence, or recorded fact out of the decision table. Decision facts are edited only in the decision table.
