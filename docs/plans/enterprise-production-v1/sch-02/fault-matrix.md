# SCH-02 fault matrix (specs/05 step 4 list mapped to DUR-01..03)

Rows marked "other task" are outside the outbox and are listed so nothing is silently dropped.

| Fault                                         | Outcome                                                                                                                             | Proof                                                             | DUR    |
| --------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- | ------ |
| Crash after DB commit, before enqueue         | Row stays `pending`; any later publisher sends it                                                                                   | test "a crash after commit ..."                                   | 01, 03 |
| Outbox insert fails in claim                  | Run and cursor roll back; slot claimable later                                                                                      | test "an outbox failure rolls back ..."                           | 01     |
| Enqueue succeeds, ack lost                    | Retry with same transport name; queue answers `exists`; still one run, one outbox row                                               | 2 lost-ack tests                                                  | 01, 03 |
| Queue lacks name dedupe                       | Duplicate message possible; DB identity (run id, unique live execution) keeps one logical run                                       | lost-ack test without dedupe                                      | 01     |
| Simultaneous claim (dispatchers)              | SCH-01 row claim; unique run per slot                                                                                               | SCH-01 tests                                                      | 01     |
| Simultaneous publish                          | SKIP LOCKED plus lease; each event published, no double without lease expiry                                                        | concurrent publishers (4, 6)                                      | 01     |
| Publisher dies mid-publish                    | Lease expires, event reclaimed, `attempts` advanced                                                                                 | stale lease recovery, reconcile test                              | 03     |
| Lease expiry with old publisher alive         | Old publisher's CAS fails when a newer fence exists; remote duplicate tolerated                                                     | stale holder tests                                                | 02, 03 |
| Stale publisher after terminal state          | CAS and terminal trigger refuse overwrite                                                                                           | fencing test, direct UPDATE 55000                                 | 02     |
| Provider 429 / 5xx                            | Retryable; capped exponential backoff with jitter; class stored                                                                     | poison test, cap test                                             | 03     |
| Poison payload / non-retryable                | `abandoned` at once, class `unknown` if unsanitary; visible in DB                                                                   | non-retryable test                                                | 03     |
| Exhausted retries                             | `abandoned` with attempts and class; never auto-replayed                                                                            | poison test                                                       | 03     |
| Queue retention loss / deleted task           | Row `published` but task gone: recoverable only by reconciling worker side (SCH-03 durable reconciler re-enqueue); not covered here | gap, other task                                                   | 03     |
| Missed tick                                   | Next `claimDue` catches up (SCH-01)                                                                                                 | SCH-01 tests                                                      | 01     |
| Schedule edit / revoke / pause during enqueue | Publisher does not check authority; worker rechecks (other task)                                                                    | other task                                                        | 01     |
| Worker death / fencing of task state          | Other task                                                                                                                          | other task                                                        | 02     |
| DB failover                                   | Commit is the durability point; unpublished rows survive and publish later                                                          | covered by crash-after-commit logic, no failover drill (operator) | 03     |
| Directory outage                              | Other task                                                                                                                          | other task                                                        | n/a    |
