# AGT-00 gap map

Each proposed addition for AGT-01..07 maps to existing code or a documented gap. Line numbers are at base 16050f5.

## AGT-01 versioned DAG execution

| Proposed addition                         | Existing                                                                                                                    | Gap                                                                                                                                                         |
| ----------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Dependencies and cycle/dangling rejection | `depends_on` (migration 0019); `checkPlan` (`tasks.ts:709`), `hasDependencyCycle` (`teamwork-policy.ts:79`)                 | Covered at plan edit time. Pinned by `teamwork.test.ts` "refuses a plan whose dependencies form a cycle"                                                    |
| Revision CAS                              | `tw_plans (task_id, version)`, live-plan unique index, `editPlan` `baseVersion` (`tasks.ts:799`), `decidePlan` digest check | CAS is plan-level only; assignments carry `plan_version`, no graph revision on node writes. `evaluateGraphCas` freezes the rule                             |
| Fenced claim, one owner                   | `claim` uses `for update skip locked` and a lease token (`worker.ts:90`); `tw_jobs_live` unique index                       | Pinned by "two workers drain the same queue" test. Job-level fence only; node status move is `where status = $from`, no fencing token on the node           |
| Failure propagation                       | `releaseDependents` (`worker.ts:162`)                                                                                       | **Defect**: `queued -> failed` is illegal in `ASSIGNMENT_TRANSITIONS`, so the dependent stays queued and the task stays `running` (pinned). AGT-01 must fix |
| Restart recovery                          | Lease expiry reclaim, `MAX_JOB_ATTEMPTS` quarantine, start-time lease expiry (`worker.ts:75-77`, `createWorker`)            | Only jobs recover; no graph-level reconcile pass                                                                                                            |
| Cancellation propagation                  | `cancelTask` (`tasks.ts:1048`), `settleCancel` (`worker.ts:119`)                                                            | Task-level cancel at a step boundary; no per-node cancel or committed propagation policy                                                                    |
| No replay of completed effects            | `followUpRescope` requeues succeeded assignments (`tasks.ts` ~930, `succeeded -> queued` allowed)                           | **Divergence** from the frozen table (listed in `KNOWN_ASSIGNMENT_DIVERGENCES`). AGT-01 decides: new node per rerun, or fence it                            |
| `retry_wait`                              | `requeue` bumps `attempt` on explicit user retry                                                                            | No automated retry, no backoff time column. Needs a migration (coordinator reserves)                                                                        |
